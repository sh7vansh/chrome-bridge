# 007 — Ambient Python Virtualenv Site-Packages Discovery

**Parent:** [Map: Adaptive & Context-Aware Chrome Bridge Architecture](file:///home/shivansh/chrome-bridge/issues/map.md)

**What to build:**
Enable subagents and REPL processes running under ambient system Python to automatically discover and attach the runtime `.venv` virtual environment site-packages via `site.addsitedir()`, providing transparent access to all installed dependencies without requiring explicit virtual environment activation.

## Acceptance criteria

- [x] `chrome_sdk.py`, `repl_engine.py`, and `mcp_server.py` detect `.venv` in the resolved runtime directory and call `site.addsitedir()` on the platform-appropriate `site-packages` path.
- [x] `.agents/skills/chrome-bridge/SKILL.md` includes site-packages auto-discovery in the subagent bootstrap snippet.
- [x] Subagent scripts running under an unactivated Python interpreter can import all third-party dependencies installed in `.venv`.
- [x] Automated tests verify `site.addsitedir()` is called correctly when `.venv` is present.
