# Chrome Bridge Domain Model

The runtime and automation architecture connecting AI agent drivers to Google Chrome via a persistent Python REPL and Native Messaging bridge.

## Language

### Core Entities

**Driver**:
The AI model or agent interacting with the browser exclusively by executing Python scripts against the runtime layer.
_Avoid_: Agent worker, bot, prompt controller

**Python REPL Runtime**:
A stateful, persistent in-memory Python execution environment that manages browser subroutines, batch processing, and context budgeting before returning results to the Driver.
_Avoid_: Script runner, sandbox runner, evaluation container

**Chrome SDK (`chrome`)**:
The synchronous, fluent Python standard library injected into the REPL session providing procedural browser control methods.
_Avoid_: Browser client, automation driver, playwright wrapper

**Element Ref-ID**:
A lightweight, indexed identifier (e.g. `[#1]`, `[#2]`) assigned to interactive DOM nodes to minimize token usage during page orientation.
_Avoid_: Element handle, node pointer, DOM tag

**Semantic DOM Snapshot**:
A compressed, token-optimized representation of interactive and structural elements generated by the extension for agent inspection.
_Avoid_: Accessibility dump, HTML tree, page dump

**Native Host Bridge**:
The native messaging IPC socket transport connecting the Python REPL server directly to the Chrome extension background worker.
_Avoid_: Web socket server, proxy port, daemon connection

**Polymorphic Locator**:
A flexible identifier argument accepted by Chrome SDK action methods, seamlessly resolving integer indexes (e.g. `1`), Ref-ID tokens (e.g. `"[#1]"`, `"#1"`), or standard CSS selectors.
_Avoid_: Target query, element selector string, node specifier

**Tab Handle (`Tab`)**:
An object-oriented handle representing a specific browser tab, providing scoped browser actions and state inspection independent of the active tab.
_Avoid_: Window frame, tab instance pointer, browser page object

**Diagnostic Auto-Snapshot**:
A token-budgeted Semantic DOM Snapshot automatically injected into action failure exception payloads to facilitate single-turn Driver self-healing.
_Avoid_: Error snapshot, debug dump, recovery screenshot

**Action Interceptor**:
An overlapping DOM node (such as a modal backdrop, sticky header, or cookie consent overlay) that obstructs pointer hit-testing coordinates during user interaction attempts.
_Avoid_: Blocking element, overlay blocker, click blocker
